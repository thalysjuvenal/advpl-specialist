# advpl-specialist — Copilot Instructions

Use as skills em `/skills/` e agentes em `/agents/` como contexto para geração e revisão de código ADVPL/TLPP.

## Convenções rápidas
- Notação Húngara: cNome, nValor, lOk, aItens
- Prefixos de módulo: FAT, COM, EST, FIN, CTB, FIS
- Arquivos ADVPL devem incluir #Include "TOTVS.CH"

## Desenvolvimento de docs
- `cd documentation && npm ci`
- `cd documentation && npm run dev`
